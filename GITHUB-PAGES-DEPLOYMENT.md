# GitHub Pages Deployment Guide - Campus Desk

## 🌐 Deployment Options

### Option 1: Frontend Only (GitHub Pages) + Backend (Free Tier Services)

Since GitHub Pages only supports static sites, we'll deploy the frontend to GitHub Pages and the backend to a free tier service.

## 🚀 Frontend Deployment to GitHub Pages

### Prerequisites
- GitHub account
- Git installed
- Node.js and npm installed

### Step 1: Install gh-pages
```bash
cd client
npm install --save-dev gh-pages
```

### Step 2: Update package.json
Your `client/package.json` should include:
```json
{
  "homepage": "https://yourusername.github.io/campus-desk",
  "scripts": {
    "predeploy": "npm run build",
    "deploy": "gh-pages -d build"
  }
}
```

### Step 3: Deploy to GitHub Pages
```bash
cd client
npm run deploy
```

### Step 4: Enable GitHub Pages
1. Go to your GitHub repository
2. Settings → Pages
3. Source: Deploy from a branch
4. Branch: gh-pages
5. Folder: / (root)

## 🖥️ Backend Deployment Options

### Option A: Render (Recommended)
1. Create account at [render.com](https://render.com)
2. Connect your GitHub repository
3. Create a new "Web Service"
4. Build Command: `cd server && npm install`
5. Start Command: `cd server && node index.js`
6. Add environment variables

### Option B: Heroku (Free Tier)
1. Install Heroku CLI
2. Login: `heroku login`
3. Create app: `heroku create your-app-name`
4. Deploy: `git push heroku main`
5. Set environment variables

### Option C: Railway
1. Create account at [railway.app](https://railway.app)
2. Connect GitHub repository
3. Deploy automatically
4. Configure environment variables

## 🔧 Configuration Updates

### Frontend API Configuration
Update your client to point to the deployed backend:

```javascript
// In your API configuration
const API_BASE_URL = process.env.NODE_ENV === 'production' 
  ? 'https://your-backend-url.herokuapp.com' 
  : 'http://localhost:5000';
```

### Environment Variables
Set these in your backend deployment:

#### Required Environment Variables:
- `MONGODB_URI` - MongoDB Atlas connection string
- `JWT_SECRET` - Your JWT secret key
- `NODE_ENV` - Set to `production`
- `PORT` - Usually set by the platform

#### MongoDB Atlas Setup:
1. Create free account at [MongoDB Atlas](https://www.mongodb.com/cloud/atlas)
2. Create a free cluster
3. Create database user
4. Get connection string
5. Add to environment variables

## 🔄 Automatic Deployment

### GitHub Actions for Frontend
Create `.github/workflows/deploy.yml`:

```yaml
name: Deploy to GitHub Pages

on:
  push:
    branches: [ main ]

jobs:
  build-and-deploy:
    runs-on: ubuntu-latest
    steps:
    - uses: actions/checkout@v2
    
    - name: Setup Node.js
      uses: actions/setup-node@v2
      with:
        node-version: '18'
        
    - name: Install dependencies
      run: |
        cd client
        npm install
        
    - name: Build and deploy
      run: |
        cd client
        npm run deploy
      env:
        GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

## 📝 Important Notes

### CORS Configuration
Update your backend CORS settings:
```javascript
const corsOptions = {
  origin: [
    'http://localhost:3000',
    'https://yourusername.github.io/campus-desk'
  ],
  credentials: true
};
```

### Socket.io Limitations
Socket.io may not work on all free tiers. Consider:
- WebSockets alternatives
- Long polling fallback
- Platform-specific WebSocket solutions

### Security Considerations:
1. Use HTTPS in production
2. Validate all inputs
3. Secure your MongoDB Atlas cluster
4. Use strong JWT secrets
